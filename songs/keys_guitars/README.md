# Keys and guitars

Recorded piano, keyboard and guitar programs; twelve new native keyboard recipes; controlled four-bar auditions
and eight authored musical starters. Open [index.html](index.html) through the local listening server.
The comparison players preserve position when switching between sounds in the same benchmark family.

Run `python tools/keys_guitar_palette.py --prepare --render --gallery --audit` to reproduce. `--prepare` regenerates
only the controlled auditions; the hand-authored templates stay editable. `--only ID` restricts rendering.
See [the palette guide](../../docs/KEYS_GUITAR_PALETTE.md) for source credits, controls, performance notes and limits.
