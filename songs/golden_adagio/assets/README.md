# Instrument portraits

Generated with the built-in OpenAI image tool for this listening page. These are illustrations, not photographs of the recorded instruments.

Shared art direction: one centered, complete, recognizable instrument; painterly realism with fine engraved detail; antique gold and ivory against dark midnight navy (#101b25); no people, text, logos or border; generous margin around the instrument for compact display.

Separate subjects: violin, cello, bowed double bass, concert flute, French horn, concert harp, grand piano and pipe organ. Native generated PNGs are preserved here; the page crops none of the instrument and uses CSS to fit each portrait. Original generated files remain in the Codex generated-images folder.
