# Skill evaluation songs

Scores written by fresh agents that were given only the `songmap-compose` skill and a brief. They test whether the skill's instructions are enough to compose well.
- `wetland.sm`: a 75 s nature documentary cue.
- `teaser.sm`: a 48 s product teaser.
- `batteries.sm`: a 70 s science explainer.

New evaluation runs go here too. They appear in the textbook's Songbook for review.
