# Previous fixed-rate binaural drafts

These snapshots preserve the two five-minute scores, full/pairs MP3s and verification receipts before the beat-frequency correction. Their audible centers followed the harmony, but the interaural differences used independent fixed-Hz rates and a golden ladder.

The current scores use `beat=octave octaves=5`: each difference is its own carrier frequency divided by 32. `before.json` preserves the instrumental event digests; both current instrumental digests match. No instrumental notes were rewritten for this correction. Explicit numeric beat mode remains supported for reproducing these historical drafts.
